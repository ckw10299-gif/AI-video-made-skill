# 确认后自动提交工作流

## 目录

1. 适用范围与两阶段门禁
2. 浏览器与素材规则
3. 原生素材引用
4. 提交前审计与完成判定
5. 本地工作台代码与启动方式

## 适用范围

用于用户选择“提示词确认后自动提交生成”的任务。当前目标站点为 AI 工坊，默认进入“工坊 -> 视频生成 -> 个人”。自动化只负责提交任务，不等待成片。

## 强制两阶段

### 第一阶段：分析与确认

1. 读取视频或剧情 brief。
2. 抽帧、分析并输出完整提示词。
3. 根据用户意见持续修改。
4. 等待用户明确确认。

### 第二阶段：上传与提交

1. 去掉【镜头设计思路】。
2. 选择匹配画风的素材。
3. 逐个上传素材并记录网站标签。
4. 输入提示词并建立原生 `@` 引用。
5. 校验参数后点击生成。
6. 确认进入生成队列后立即停止。

不得在第一阶段提前提交，也不得在第二阶段等待视频渲染完成。

## 浏览器原则

- 优先使用可控制现有登录态的 Chrome 控制能力。
- 使用独立窗口或独立标签，不接管用户正在操作的页面。
- 不要求用户反复升级扩展、刷新页面或手动点选。
- 登录失效或权限不足时，明确指出唯一需要用户完成的登录动作；完成后继续自动执行。

## 素材规则

- 物料库路径由用户提供，不能写死在提示词里。
- 三渲二、赛璐璐和动画任务选择动漫区素材；真人短剧选择真人区素材。
- 角色素材只绑定【角色】，物品与噜咪素材只绑定【其他参考】。
- 按引用顺序逐个上传。并行上传会导致网站标签与本地顺序错位。
- 素材选择以名称、画风和用途共同匹配，不能只依赖文件序号。

## 原生素材引用

网站中的素材引用必须是原生 mention 节点，而非普通文本。已知页面结构可按以下顺序识别：

- 提示词编辑器：`.cr-vid-prompt-editor`
- 视频素材上传入口：`.cr-frame-trigger--vid:not(.cr-frame-trigger--gallery)`
- `@` 菜单：`.cr-at-menu`
- `@` 菜单项：`.cr-at-menu-item`
- 素材标签：`.cr-at-label`
- 已绑定引用：`.cr-inline-mention`
- 参数按钮：`.cr-pill-btn`
- 画幅选项：`.cr-ratio-grid`
- 时长选项：`.cr-ratio-grid--duration`
- 空间选择卡：`.vis-card`
- 生成按钮：`.cr-send-btn`

页面更新时选择器可能变化。操作前先通过可见文本和 DOM 结构复核，不能盲点。

成功绑定至少满足：

1. 编辑器中存在 `.cr-inline-mention`。
2. `data-mention-label` 与目标素材标签一致。
3. `data-mention-url` 非空。

## 提交前审计

- 当前功能为“视频生成”。
- 当前空间为“个人”，不是“当前空间”。
- 画幅、分辨率、时长与提示词一致。
- 所有必需素材均已上传且标签记录无误。
- 每个 `@` 都是原生素材节点。
- 上传版提示词不含【镜头设计思路】。
- 文本中没有临时本地路径、素材序号或调试说明。

## 完成判定

出现以下任一状态即可结束：

- “视频生成任务已提交”
- “生成中”
- “AI 正在创作中”

此时向用户报告“已进入生产流程”，不继续等待、不轮询完成状态。

## 代码目录

`automation/workbench-mvp/` 是可运行的本地工作台原型，包含：

- React 需求表单与提示词修改界面。
- Express API、OpenAI Responses API 接入和基础抽帧接口。
- 本地素材库扫描与任务队列。
- Chrome 扩展桥接原型，用于逐个上传素材、建立 mention 和提交任务。

生产操作优先使用浏览器控制能力；扩展桥接属于可选原型，站点 DOM 变化后需要重新验证选择器。

## 启动本地工作台

```powershell
cd automation\workbench-mvp
Copy-Item .env.example .env
npm install
npm run dev
```

在 `.env` 中配置 `OPENAI_API_KEY` 和 `BRIDGE_ASSET_ROOT`。前者用于生成和修改提示词；后者限制浏览器桥接可读取的素材根目录，防止任务访问物料库以外的文件。

Chrome 扩展以开发者模式加载 `automation/workbench-mvp/bridge-extension`。扩展只用于已登录的目标站点，并从本地 `8787` 端口轮询已经确认的任务。

也可以直接用脚本创建待审核任务：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/submit-approved-task.ps1 `
  -PromptPath "D:\task\prompt.txt" `
  -AssetsPath "automation\examples\assets.example.json" `
  -Ratio "9:16" `
  -Duration 10
```

默认只绑定素材并停在待提交状态。只有已经获得用户确认时才增加 `-Submit`。
