# 参考视频与平面素材完整生产包工作流

## 目标

把用户提供的一个参考视频与若干平面素材转换成可以直接进入AI视频生成环节的完整生产包：

```text
参考视频 + 平面素材
-> 视频证据分析
-> 必要三视图
-> 首帧或关键参考图
-> 完整中文视频提示词
-> 标准文件夹交付
```

该流程是通用流程，不限定巨物Boss。可用于：

- 剧情短剧与买量前贴
- 角色或宠物展示
- 进化、黑化、净化与换装
- Boss战、跑图与技能PV
- 固定镜头ASMR与护理视频
- 真人短剧转三渲二
- 多角色对话、排队、开蛋、融合等连续剧情

## 输入

### 必需输入

1. 一个可读取的参考视频。
2. 一个或多个平面素材，或包含素材的编号文件夹。

平面素材可以是角色立绘、宠物立绘、Boss设计、道具、服装、场景或首尾帧。文件名优先表达对象名称和作用，例如：

```text
主角.png
宠物.png
boss.png
进化果实.png
场景.png
```

如果文件名不清楚，必须查看图片确认。不得仅按上传顺序猜测。

### 可选输入

- 画风与画幅
- 需要替换的角色或道具
- 固定台词与卖点
- 目标时长
- 是否批量处理
- 是否确认后自动提交生成

## 第一阶段：分析参考视频

先使用 `scripts/analyze-video.ps1` 抽帧并读取：

- `metadata.json`
- `opening.jpg`
- `overview.jpg`
- `scene-frames`

关键动作不清楚时增加0.5秒或1秒密集抽帧。记录以下证据：

1. 视频总时长、画幅与镜头数量。
2. 首帧构图、角色数量、站位、朝向与尺寸关系。
3. 固定机位或移动机位，是否切镜。
4. 每个角色完整动作链及动作发生顺序。
5. 场景变化、光线变化和特效节点。
6. 台词、音效和节奏落点。
7. 最后一个稳定画面或产品落点。

分析结果必须驱动后续所有图片与提示词。未看清视频前不生成三视图或首帧。

## 第二阶段：建立素材映射表

为每个平面素材记录：

| 对象 | 文件 | 剧情作用 | 是否需要三视图 | 需要出现在哪些镜头 |
|---|---|---|---|---|
| 主角 | 主角.png | 推动剧情 | 是 | 全程或指定镜头 |
| 宠物 | 宠物.png | 同行、战斗或展示 | 视运动需要 | 指定镜头 |
| 道具 | 道具.png | 触发剧情 | 通常否 | 使用道具的镜头 |

只有满足以下任一条件时生成三视图：

- 视频会展示该角色正面、侧面和背面中的两个以上角度。
- 角色需要奔跑、转身、飞行、战斗、跌落或环绕展示。
- 后续首帧必须使用角色背面，而原平面图没有清晰背面。
- 角色会在多个镜头反复出现，需要提高身份稳定性。

通常不为纯道具、单次静物、背景群众或只出现局部的对象生成三视图。用户明确要求全部生成时除外。

## 第三阶段：生成三视图

每个需要三视图的对象单独生成一张图：

1. 横向画布，纯净暖白背景。
2. 从左到右：正面、右侧面、背面。
3. 全身完整、同一基线、同一尺寸。
4. 正交视图、自然中立姿势，不使用剧情动作。
5. 保留平面图的颜色、花纹、配饰、身体结构和比例。
6. 三视图画风与最终视频画风一致；真人视频需要生成可用于写实一致性控制的角色设定图，动画视频使用对应三渲二或赛璐璐设定图。
7. 不添加文字、标签、水印、额外角色和未提供配饰。

生成后必须目视检查三个方向是否为同一角色。方向或特征错误时先修复三视图，不继续生成首帧。

## 第四阶段：确定需要的参考图

参考图不是固定只有一张。根据视频结构选择：

### 单首帧

适用于固定镜头、连续跟拍、单场景展示、ASMR和6秒左右的连续动作视频。生成一张最能建立构图、站位与方向的首帧。

### 首帧加关键帧

适用于明显变身、进化、黑化、场景切换或终局形态。可生成：

- 首帧：起始状态。
- 转折帧：关键动作或变化触发。
- 终局帧：最终形态或群像定格。

### 分段参考图

视频需拆成两段或多段时，每段分别生成独立首帧。后一段不能假设生成模型知道前一段最后一帧。

## 第五阶段：生成首帧或关键参考图

首帧必须复现参考视频的构图功能：

- 原视频固定镜头，就保持固定构图和人物位置。
- 原视频背后跟拍，就让主角朝前、背对镜头。
- 原视频侧向跟拍，就让角色沿画面横向排列。
- 原视频近景ASMR，就保持手、工具和护理对象的相对位置。
- 原视频多人对话，就建立准确的左右站位与视线关系。

首帧只描述静态时刻，不把整个视频动作链压进图片提示词。绘画提示词推荐结构：

```text
# 首帧绘画提示词

【画风】
【场景】
【人物】
【其他参考】（需要时）
【具体内容】
【正向提示词】
【负向提示词】
```

首帧使用生成后的三视图作为角色身份与方向依据，并使用用户提供的场景、道具素材作为对应参考。

## 第六阶段：生成视频提示词

提示词必须匹配参考视频的实际时长、构图、镜头数量和动作顺序，不能固定写成6秒，也不能默认巨物Boss结构。

### 动画、三渲二与赛璐璐

剧情类按分镜输出，每镜包含时间轴、运镜、景别、场景、画面、具体内容和配音。连续展示类可以使用连续动作段落，避免无意义切镜。

### 真人短剧

每个分镜使用白描式连续段落，把视角、站位、动作、表情、群众反应和台词按发生顺序写在一起，不把运镜、景别、配音拆散。

### 固定镜头ASMR

写清固定机位、手部进入方向、护理对象位置、工具触感、动作节奏与同步声音。每条视频集中完成一种主要护理动作，不塞入过多步骤。

### 动作或技能PV

写清角色运动方向、镜头跟随关系、主体相对位置和技能完整动作。主角只执行必要动作，避免同时加入转身、跳跃、闪避和多段复杂运镜。

视频提示词使用统一结构：

```text
# 视频生成提示词

【画面风格】
【场景】
【角色】
【其他参考】（需要时）
【具体内容】
【正向提示词】
【镜头设计思路】
```

提示词内角色、道具和场景称呼必须与素材映射表一致。用户提供的固定台词逐字保留。

## 第七阶段：标准交付

保留用户原文件夹名称。每个文件夹至少包含：

```text
完整提示词.txt
首帧图片.png
```

根据当次任务实际生成的内容补充：

```text
主角三视图.png
宠物三视图.png
boss三视图.png
角色名三视图.png
关键帧01.png
关键帧02.png
终局参考图.png
```

命名必须使用对象名称，不使用“图片1、图片2”。`完整提示词.txt` 使用UTF-8编码，依次放入首帧或关键帧绘画提示词、完整视频提示词。批量任务必须一组素材对应一个独立文件夹，禁止跨组混用。

## 巨物Boss模板

当参考视频属于“主角与宠物向巨物Boss前进，Boss原地展示大招”结构时，再读取 [giant-boss-first-frame-workflow.md](giant-boss-first-frame-workflow.md)，使用其中的Boss占比、顶部和底部安全区、严格背面和大招构图规则。其他视频类型不套用这些比例。

## 质量检查

### 视频分析

- 是否真正读取了视频并确认时长、机位、切镜和动作。
- 是否按原视频实际结构决定参考图数量与提示词时长。

### 素材一致性

- 三视图是否继承原平面图的稳定特征。
- 首帧是否使用三视图建立正确角度和方向。
- 不同文件夹是否发生角色串用。

### 构图与动作

- 首帧是否只描述一个静态时刻。
- 提示词是否包含完整动作链，而不是把动作错误地写进首帧。
- 镜头与人物方向是否符合参考视频的空间逻辑。

### 交付

- 是否保留原文件夹名称。
- 是否包含完整提示词TXT、首帧，以及本次确实需要的三视图和关键帧。
- 文件名是否使用角色或对象名称，内容是否UTF-8可读。
