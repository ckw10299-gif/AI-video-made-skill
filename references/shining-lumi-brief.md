# 《闪耀吧噜咪》项目 Brief

本文件记录对话中已经确认、可用于 AI 视频买量素材的项目信息。它是提示词本地化约束，不替代完整游戏设计文档。未在此文件或当前用户需求中确认的系统、道具和数值，不得自行补充。

## 1. 产品定位

- 产品名：《闪耀吧噜咪》。
- 核心体验：发现、捕捉、收集、培养和进化不同噜咪，扩充噜咪图鉴。
- 常用广告情绪：捉宠爽感、稀有度追求、收集满足、轻松养成、自动化解压、从弱到强的逆袭。
- 常用剧情结构：普通与稀有对比、被嘲讽后逆袭、开蛋反转、进化或净化、宠物互动、技能展示、生存危机中的噜咪选择。

## 2. 核心术语与层级

- **噜咪**：游戏中的宠物统称。
- **普通噜咪**：基础层级，用于建立前后反差。
- **彩色噜咪**：明确的稀有目标。涉及稀有度对比时优先使用“彩色噜咪”，不要擅自改写为“高级噜咪”。
- **星彩噜咪**：比彩色噜咪更稀有、更具视觉冲击力的形态或层级。只有用户需求明确涉及时使用。
- **彩色全图鉴**：收集卖点，表示彩色噜咪图鉴完成度。
- **进化**：噜咪可以从初始形态升级为更强或更华丽的形态。变化前后必须继承角色身份与关键外观特征。
- **黑化与净化**：可作为展示剧情。黑化需要角色和场景同步变化；净化后恢复正常，也可衔接进化为星彩噜咪。
- **噜咪蛋**：用于开蛋剧情。已确认广告语境中可出现普通蛋、金蛋和彩蛋；具体外观、数量和结果服从当前需求。
- **进化果实**：用于触发噜咪进化或净化的关键道具。
- **噜咪卡**：工坊产出的道具形式。涉及噜咪捕捉工坊时制作噜咪卡，不替换成捕捉球。

具体噜咪名称、外形、属性和技能只在用户提供角色素材或明确命名时使用。迷梦猫鲨、草龙、只鼬、小火喵、传话蛙、坤坤鸡等历史案例不能自动带入新任务。

## 4. 本地化原则

1. 先提取素材的钩子、冲突、动作顺序、镜头机制和台词功能，再把表层玩法替换为《闪耀吧噜咪》的真实卖点。
2. 角色之间的强弱差距优先通过彩色噜咪数量、星彩噜咪数量、图鉴完成度、开蛋结果或进化结果体现。
3. 视频只比拼彩色噜咪数量时，全程围绕数量写动作与台词，不改成战力、等级、捕捉设备或其他系统。
4. 真人短剧可以把噜咪做成与现场光线一致的高品质3D生物；三渲二和古早日漫则把角色、噜咪、背景和特效统一到同一画风。
5. 用户只提供少量素材时，减少同屏需要精确还原的噜咪数量；优先突出一只核心噜咪或用蛋承接结果。
6. 广告场景可以是主城、森林、冒险家协会、实验室、海边、城中村、婚礼、相亲或灾难现场，但产品落点必须回到已确认的捕捉、收集、开蛋、进化和自动捉宠体验。

## 5. 设定边界

- 不把竞品中的设备、玩法和术语直接移植进游戏。
- 不自行发明捕捉器、过滤器、战力系统、鉴定等级、融合规则、手机玩法、UI数值或后期信息包装。
- 原素材确实依赖某种机制时，先寻找已确认的噜咪对应物；没有可靠对应物时，用彩色噜咪数量、图鉴、开蛋或进化结果完成同等剧情功能。
- 后期字幕、头顶数值、标签、游戏界面和图标只在用户明确要求时写入成稿。
- “普通噜咪”“彩色噜咪”“星彩噜咪”的称呼严格服从当前任务，不擅自互换。
- 用户说只保留某个片段时，在该片段的剧情落点结束，不续写玩法展示或额外结尾。
